# FRACTRAN • CONWAY'S INFINITE MACHINE

**A living, breathing, neon-drenched tribute to John Horton Conway's 1972 esoteric masterpiece.**

This is not just another FRACTRAN simulator.  
This is a cyberpunk math cathedral built to make senior engineers, hackers, VCs, and math PhDs stop scrolling.

## Features that actually matter

- Real-time FRACTRAN interpreter with zero bugs
- Canvas particle explosions synced to every multiplication
- Instant detection of powers of 2 (the famous prime powers)
- CRT scanlines + glitch header + glassmorphism UI
- 5 legendary presets including Conway’s 14-fraction prime generator
- Live step counter, runtime tracker, exportable sequence
- Keyboard shortcuts (`SPACE` = step, `R` = reset)
- Fully responsive + mobile-ready (yes, even on your phone)
- Zero external dependencies except one Google Font (VT323)
